# MathForge

> [!WARNING]
> This project was created for educational purposes and is still under development. It may contain bugs, incomplete features, and architectural flaws. The code is not production-ready and should be used with caution.

A modular .NET mathematical library providing a collection of tools for mathematics, numerical computing, probability, graphics, cryptography, and other computational domains.

MathForge is designed as a collection of independent modules that can be used separately or combined to build mathematical applications, simulations, research tools, and other software projects.

## Features

- Modular architecture with independent libraries.
- Mathematical and numerical computing.
- Probability distributions and statistical tools.
- Cryptography and data processing.
- Graphics and computational geometry.
- Machine learning and optimization.
- Graphs and dependency-related utilities.
- Source generators and dependency injection support.

## MathForge.Maui

`MathForge.Maui` is a .NET MAUI showcase application for the MathForge ecosystem.

It provides a visual interface for exploring and demonstrating the functionality of the MathForge modules.

The application serves as a showcase for mathematical algorithms, calculations, visualizations, and other capabilities provided by the library.
